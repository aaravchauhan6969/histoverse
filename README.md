# 🚀 Histoverse

Histoverse is a modern storytelling platform that reimagines how users explore Indian epics and historical narratives.

The project aims to provide a cleaner and more engaging experience compared to traditional text-heavy platforms by organizing stories into structured arcs and presenting them through an interactive user interface.

## ✨ Features

* Interactive and modern UI
* Animated particle background
* Explore Stories section
* Ramayana divided into story arcs
* Mahabharata divided into story arcs
* Indian historical heroes section
* Responsive design
